# OCLR IRC v0.8.3

公開預覽版，整合最近的帳號介面與登入恢復功能。

## 更新內容

- **登出圖示**：IRC／OCLR 帳號頁、側欄與停止重連入口統一使用 log out 圖示，保留本地化操作提示及無障礙名稱。
- **osu! 頭像**：帳號頁從 osu! 公開個人頁取得頭像並快取本機；24 小時內重用，更新失敗時沿用有效快取，沒有可用圖片則顯示名字首字母。底線與空格等價，圖片下載不使用 IRC 密碼或 OCLR token。
- **恢復 IRC 登入**：「設定 → 一般」新增「啟動時恢復上次 IRC 登入」，預設關閉。啟用時可安全保存目前成功登入的帳號，正常退出後下次啟動自動連線；手動登出、忘記憑證或停用選項會取消恢復。舊版語言及背景偏好保留，不自動啟用新選項。
- **系統匣**：包含已合併的本地化退出入口，可正常結束背景執行的客戶端。
- 沿用免費 HeroUI，保留 900×640 版面、登入世代隔離與既有房間操作保護。

## 下載與更新

Windows x64 提供安裝精靈 EXE 及備用 ZIP；macOS Apple Silicon arm64 提供 DMG 及備用 ZIP；Linux x64 提供 tar.gz。使用下載頁的 SHA256SUMS.txt 核對成品，實際提交及簽章資訊見 build-info.json。更新前正常結束舊版，保留原使用者資料。

自動登入沿用系統安全儲存，密碼不寫入偏好檔。首次更新後，於設定自行開啟恢復登入；不恢復舊房間指令或 OCLR 授權／投影。

## 驗收範圍

- Pre-release、非 Latest；不代表完整 MVP 或所有實機驗收完成。
- Windows 尚未配置發行簽章；macOS App／DMG 的正式 Developer ID 簽章及 Apple 公證，以本版 Release CI 與 build-info.json 為準。
- Linux 憑證保存／自動登入仍因安全 provider 驗收未完成而停用。無可用安全儲存時使用手動登入，不回退明文。
- CI 使用合成 IRC／crypto；真實 Bancho、OAuth、IME、休眠及實機 provider 等 gate 依既有追蹤。
