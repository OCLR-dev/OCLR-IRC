# OCLR IRC v0.8.4

本版納入 Liru 圖標及側欄品牌區調整（#86／#87）。公開資產與簽章狀態以實際 GitHub Release 及其建置資訊為準。

## 更新內容

- **Liru 圖標**：主圖標整合 Liru 角色、OCLR 字標與 IRC 對話徽章，接入 Windows EXE／安裝程式、macOS App、Linux 桌面入口，以及側欄與關於頁。
- **系統匣圖示**：使用獨立的無字樣角色圖案；macOS 提供適配明暗模式的 1x／2x 單色模板。
- **高解析度側欄**：視窗至少 1440×800 時圖標放大至 64px，1920×800 時為 80px，品牌文字同步放大。使用 256px 圖像來源，900×640 與較矮視窗保留 40px 緊湊尺寸。
- **打包檢查**：驗證原生圖標與封裝後畫面載入，修正 Windows ASAR 資產檢查的路徑分隔符，加入 ASAR／未封裝目錄及損壞圖檔回歸。
- **README**：修正介紹粗體渲染，加入應用圖標，並以表格整理三平台下載格式。
- Liru 原角色設計 JerrYamada，改編圖像採 CC BY 4.0；來源、署名與生成提示見 [Liru 應用圖標](../liru-app-icon.md)及隨包聲明。

## 版本與驗證

package.json、package-lock 的套件／根版本與介面備援版本同步為 0.8.4。沿用 Windows x64 EXE／ZIP、macOS arm64 DMG／ZIP、Linux x64 tar.gz 的發行格式。

這是版本準備記錄；發布需依 Release CI 核對版本 tag、三平台建置、正式 macOS 簽章公證與成品校驗。一般 PR CI 的 macOS 成品為 ad-hoc 測試包。完整 MVP、實機 IME／系統匣／安全 provider 等驗收仍依既有追蹤。
