# OCLR IRC v0.8.8

包含 #123 與 #125 的修復，公開下載與簽章結果以本版 GitHub Release 為準。

## 更新內容

- 房間設定改為按需同步：加入／重連、可信房間變更及操作前需要時才查詢，合併重複要求；閒置與逾時不再持續發送 `!mp settings`，保留手動更新、必要狀態同步與過期資料檢查。
- 修復表演賽面板資料驗證失敗：支援網站已保存的 EX 宣告、跳 Ban 順序及 EX 人數；仍驗證身份、版本與事件順序。
- 修正聊天歷史煙霧測試的等待條件：等待虛擬清單實際顯示最新資料，再驗證歷史位置與回到最新訊息。

## 發行

版本與介面為 0.8.8。提供 Windows x64 Setup EXE／ZIP、macOS arm64 DMG／ZIP、Linux x64 tar.gz。三平台檢查、打包及資產校驗通過，macOS App／DMG 完成 Developer ID 簽章與 Apple 公證後公開為 Pre-release、非 Latest。

更新桌面客戶端後重新開啟場次面板。真實場次與 Bancho 操作未在開發測試中執行；本版不代表完整 MVP 或實機驗收完成，Linux 憑證保存仍停用。
