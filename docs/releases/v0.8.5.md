# OCLR IRC v0.8.5

整合 v0.8.4 後已合併的介面與設定更新（#92、#94、#96、#98、#100、#102）。公開資產與簽章狀態以本版 GitHub Release 及其建置資訊為準。

## 更新內容

- **裁判工作臺**：帳號連線與 OCLR 場次整合在同頁，管理 IRC／OCLR 連線、帳號配對、網站投影及本人指派場次；原「房間記錄」改為「IRC 聊天」。移除側欄重複的「裁判工作台／01」標識。
- **記錄中心**：本機日誌與操作記錄合併為 HeroUI 分頁，保留聊天範圍、匯出／清除及未確認操作核對；切換分頁會清除未提交的確認狀態。
- **OCLR 背景更新**：場次及裁判面板預設自動更新，設定可關閉；移除例行的資料過期／更新完成提示，保留實際錯誤與操作有效性檢查。
- **簡化介面**：IRC 已連線頁移除重複登出圖示，統一由左側欄登出；新建房間不再插入額外的房名載入行。
- **macOS 圖示**：macOS 26+ 改用原生 Icon Composer 圖示目錄，避免角色縮在額外底框內；保留舊系統 ICNS，Windows／Linux 圖示及系統匣圖示沿用既有設計。
- **小視窗檢查**：裁判工作臺、記錄分頁及聊天／房內工具沿用 900×640 合成介面驗證。

## 版本與發行

package.json、package-lock 的套件／根版本及介面備援版本同步為 0.8.5。提供 Windows x64 Setup EXE／ZIP、macOS arm64 DMG／ZIP、Linux x64 tar.gz。

發布流程要求同一提交的三平台測試、打包與校驗通過，macOS App／DMG 另須 Developer ID 簽章、Apple 公證及 staple，才公開為 Pre-release、非 Latest。一般 PR CI 的 macOS 成品仍為 ad-hoc 測試包。

版本發布不代表完整 MVP 或三平台真實 IME、休眠／喚醒、系統匣、安全 provider、Bancho／OCLR 聯調驗收完成。Linux 憑證保存維持停用；既有實機與外部依賴追蹤保留。
