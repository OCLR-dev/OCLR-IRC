# OCLR IRC v0.8.0

公開預覽版，包含 v0.7.0 之後的工作區、場次工具與可靠性更新。

## 更新內容

- **精簡工作區**：移除重複的頂部導覽／版本與底部連線橫列，連線集中於左側帳號；等待提示固定於房間標題區，不再推動聊天版面。
- **房內場次工具**：同步目前場次的本輪圖池與兩隊名單，可選圖複製換圖／Mods 指令。逐人邀請先核對房間、隊伍、UID 與玩家名稱，再人工確認；送出不代表玩家到場。
- **BP 同步**：接收網站已保存的 Ban／Pick 通知，沿用受限命令與逐步觀測核對換圖、Mods。
- **回執與隱私**：區分未送出與結果不明，精確比對地圖連結；網站來源操作與關聯房間不混入 IRC-only 歷史，晚到或重複的開房回覆仍受保護。
- **邀請穩定性**：等待已排程的 settings／listrefs 完成後才建立預覽，避免確認時因背景查詢而失效；保留權限、節流、一次性確認與不重送。

## 使用及驗收範圍

- 延續公開 Pre-release 發布方式，並非完整 MVP／三平台實機驗收完成宣告。
- Windows x64、Linux x64 與 macOS arm64 的成品、校驗碼及簽章狀態，以本次 Release CI 與附帶 build-info.json 為準。
- BP 自動同步需網站與桌面皆為相容新版，更新後重新連接。完整 context、正式 lineup 與批次自動邀請仍另行追蹤。
- Linux 憑證保存仍停用；真實 Bancho 玩家狀態、IME、OS 安全儲存、系統匣與升級／復原仍需實機驗收。
