# OCLR IRC v0.8.6

整合 v0.8.5 後已合併的裁判工具改進（#106、#108、#110、#112）。公開資產與簽章狀態以本版 GitHub Release 及其建置資訊為準。

## 更新內容

- **查詢圖示區分**：讀取房間設定使用齒輪，裁判名單使用人員名單圖示；保留三語提示、鍵盤操作與單次查詢。
- **開啟網站執裁面板**：裁判工作臺選中對局後，可直接在系統瀏覽器開啟該場網站面板。Main 只接受已載入本人列表中的場次 ID，不向瀏覽器傳遞桌面 token。
- **按 UID 邀請隊員**：房內兩隊名單由 Main 使用唯一 osu! UID 產生 `!mp invite #UID`，移除人工輸入名稱／身份核對勾選；保留固定房間與玩家預覽、明確送出、權限及一次性驗證。送出不代表玩家到場，未知結果不重送。
- **前往網站核對配置**：場次依賴變更時，在工作臺或房內工具顯示一個「前往網站核對配置」按鈕，並移除換圖／Mods 指令列重複的提示。導向同場網站 `#referee-dependencies`，核對後由既有背景同步恢復預覽。
- **小視窗驗證**：900×640 下保留聊天輸入、獨立捲動工具欄及網站核對入口。

網站一鍵核對需部署 [OCLR-website PR #769](https://github.com/OCLR-dev/OCLR-website/pull/769)（`7bd1168bb4019dd9c940c860bd8780c7de9a58ad`）或其後版本。網站點擊時讀取最新配置再核對；已有受影響 BP 步驟時仍需先撤銷。桌面跳轉不自動寫入網站或重送 IRC。本版發行不包含網站部署。

## 版本與發行

package.json、package-lock 的套件／根版本及介面備援版本同步為 0.8.6。提供 Windows x64 Setup EXE／ZIP、macOS arm64 DMG／ZIP、Linux x64 tar.gz。

發布流程要求同一提交的三平台測試、打包與校驗通過，macOS App／DMG 另須 Developer ID 簽章、Apple 公證及 staple，才公開為 Pre-release、非 Latest。一般 PR CI 的 macOS 成品仍為 ad-hoc 測試包。

版本發布不代表完整 MVP 或三平台真實 IME、休眠／喚醒、系統匣、安全 provider、Bancho／OCLR 聯調驗收完成。Linux 憑證保存維持停用；既有實機與外部依賴追蹤保留。
