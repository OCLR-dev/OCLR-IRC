# OCLR IRC v0.8.14

- 「設定 → 一般」新增「聊天字號」。可選 10–24 px，預設 12 px。字號會立即套用到聊天訊息和輸入框，重啟後也會保留。
- 記錄中心以「加密保存已啟用」顯示日誌狀態。可使用系統安全儲存時，比賽房間收發的一般聊天會按 IRC 帳號加密保存七天，包含網站帶入或綁定的房間。

本版為公開預覽版，提供 Windows x64 EXE／ZIP、macOS arm64 DMG／ZIP 與 Linux x64 tar.gz。下載、校驗碼及 macOS 簽章資訊見 [GitHub Release](https://github.com/OCLR-dev/OCLR-IRC/releases/tag/v0.8.14)。
