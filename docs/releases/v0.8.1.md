# OCLR IRC v0.8.1

公開預覽版，包含自動帳號核對與重新整理圖示更新。

## 更新內容

- **自動帳號核對**：IRC 成功登入後，自動比對 OCLR 授權帳號名稱，底線與空格等價、忽略大小寫，移除人工確認勾選。名稱不符或任一登入未完成仍阻擋連接網站。
- **登入隔離**：重新登入可自動配對，但舊投影與晚到的 bind／sync 回覆不能沿用新登入送出指令；不自動恢復投影或重送操作。
- **統一重新整理圖示**：場次整理、面板更新、房內同步、設定／裁判名單查詢、日誌讀取及重連／重新加入使用免費 HeroUI 圖示按鈕，提供本地化提示與無障礙名稱，忙碌時停用並顯示旋轉狀態，遵從減少動態效果偏好。
- **網站房間入口**：包含網站透過受限連結重新加入指定房間的支援；保留 Main 的登入、目標及重複請求檢查。

## 使用及驗收範圍

- 延續 Pre-release、非 Latest；不代表完整 MVP 或三平台實機驗收完成。
- 提供 Windows x64、Linux x64、macOS arm64，可攜式成品、校驗碼及簽章狀態以本次 Release CI／build-info.json 為準。
- 自動配對是成功登入名稱的比對，不宣稱 IRC UID 證明。房內變更仍按原範圍預覽及確認。
- Linux 憑證保存仍停用；真實 OAuth／Bancho、IME、OS 安全儲存、休眠、系統匣及升級／復原仍分開驗收。
