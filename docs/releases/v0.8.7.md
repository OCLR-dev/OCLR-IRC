# OCLR IRC v0.8.7

整合 v0.8.6 後已合併的 IRC 與 BP 同步修正（PR #119、#120）。公開下載及簽章狀態以本版 GitHub Release 與建置資訊為準。

## 更新內容

- **改善 BP 自動同步**：尚未送出的 BP 通知會等待短暫房間查詢與共用節流，最多八秒，減少傳送前被拒絕的情況。等待期間仍核對帳號與房間；換房、斷線或已嘗試送出後不自動重送。
- **辨識 FreeMod 回覆**：支援 BanchoBot 的 `Disabled all mods, enabled FreeMod` 回覆，允許 FreeMod 房間回覆省略要求的全域 NF。其餘 Mods 仍須相符，玩家個人 Mods 仍需另外核對。
- **聊天框直接發送指令**：可輸入 `!mp` 等文字指令；Enter 送出、Shift+Enter 換行，一次最多十行，逐行驗證並遵守節流。切房或斷線會停止剩餘傳送，未知結果不重送。
- **房間自動更新**：目前選取的 MP 房間在背景讀取設定與裁判名單；預覽或操作期間暫停背景查詢，減少與操作互相阻擋。
- **恢復未知操作後的使用**：逾時仍保留「結果未知」，等待結束後允許新的房內操作；新的設定、裁判與玩家觀測只核對相同房間、連線及世代。開房的未知結果鎖定保留。

BP FreeMod 回執的網站端修正已在 [OCLR-website PR #789](https://github.com/OCLR-dev/OCLR-website/pull/789) 合併；網站需更新至該版或後續版本，兩端更新後重新連接。網站 main `e17290eb0a57c2b0be259eb46bc41a7bafe35205` 的 [CI](https://github.com/OCLR-dev/OCLR-website/actions/runs/41763407969) 已通過。本次 IRC 發行不包含網站部署。

## 版本與發行

package.json、package-lock 的套件／根版本及介面備援版本同步為 0.8.7。提供 Windows x64 Setup EXE／ZIP、macOS arm64 DMG／ZIP、Linux x64 tar.gz。

同一提交的三平台測試、打包及資產校驗通過，且 macOS App／DMG 完成 Developer ID 簽章、Apple 公證與 staple 後，才公開為 Pre-release、非 Latest。一般 PR CI 的 macOS 成品仍為 ad-hoc 測試包。

版本發布不代表完整 MVP、真實 Bancho／OCLR 聯調、實體 IME 或平台實機驗收完成；既有外部驗收追蹤保留。Linux 憑證保存維持停用。
