# OCLR IRC v0.8.9

修復 #129 的「先連接網站 IRC，再由網站開房」流程；包含 v0.8.8 的 #123 與 #125 修復。

## 更新內容

- 裁判名單僅在加入／重連房間時自動查詢一次，操作後、選圖／房間計畫與設定更新不再反覆發送 `!mp listrefs`；手動查詢保留（#131）。

- 尚未開房時，一般頻道或私訊分頁不再阻擋連接網站 IRC。
- 場次面板暫時過期時，連接前按需重讀並重新驗證帳號、場次與房間；取消或切換後不使用舊回應。
- 前置條件提示區分帳號、場次、面板、既有房間與開房記錄。未知開房記錄仍需先核對，避免重複開房。

登入相同帳號並選擇場次後，可先點「連接網站 IRC」，再由網站發出開房指令。連接本身不會建立房間；收到有效網站指令後才送出一次 make，加入後核對設定與裁判名單。

## 發行

版本、lockfile 與介面為 0.8.9。提供 Windows x64 EXE／ZIP、macOS arm64 DMG／ZIP、Linux x64 tar.gz。依既有流程，三平台驗證與資產校驗通過、macOS 正式簽章與 Apple 公證完成後公開為 Pre-release、非 Latest。實際結果以本版 Release 與建置資訊為準。

驗證使用合成資料；真實 Bancho／使用者場次未另行操作，Linux 憑證保存仍停用。
