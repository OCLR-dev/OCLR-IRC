# OCLR IRC v0.8.15

- 「設定 → 一般」可選聊天字型與時間戳。字型提供預設、襯線與等寬，時間戳提供隱藏、時分、時分秒。
- 「全員就緒」和「本局結束」通知可分別開關，也可選擇僅在視窗處於背景時通知。
- 傳送快捷鍵可選 Enter 或 Ctrl+Enter（macOS 為 ⌘+Enter）。可開關 BanchoBot 的設定和裁判名單查詢回覆摺疊，摺疊後可逐組展開。
- 手動邀請接受玩家名稱或 `#UID`。移位、換隊與移出可在房內選取玩家後預覽確認，玩家分頁集中顯示槽位和 OCLR 場次名單。

本版為公開預覽版，提供 Windows x64 EXE／ZIP、macOS arm64 DMG／ZIP 與 Linux x64 tar.gz。下載、校驗碼及 macOS 簽章資訊見 [GitHub Release](https://github.com/OCLR-dev/OCLR-IRC/releases/tag/v0.8.15)。
