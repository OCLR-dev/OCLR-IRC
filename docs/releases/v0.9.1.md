# OCLR IRC v0.9.1

## 應用程式更新

在「設定 → 關於」查看 GitHub 的最新正式版。macOS 版使用 Sparkle 自動檢查更新，Windows 安裝版也會自動檢查，並可在程式內下載及確認重啟安裝。Linux 和 Windows ZIP 版提供手動檢查與 GitHub 下載。從 v0.9.0 升級請先手動下載安裝。

## OCLR 網站整合

桌面端可接收 OCLR 網站授權關閉已完賽的比賽房間。桌面端會核對已配對的帳號與目前綁定的房間，再送出一次關房指令。

安裝包、SHA256 校驗碼及建置資訊見 [v0.9.1 下載](https://github.com/OCLR-dev/OCLR-IRC/releases/tag/v0.9.1)。
