# OCLR IRC v0.8.10

- 在裁判工作臺選擇場次後，可從「賽前準備」直接建立或加入比賽房間。開房表單會帶入可用的場次房名，待裁判核對並收到 BanchoBot 確認後切到 IRC 聊天。
- 加入房間可輸入 MP 編號、貼上比賽連結，或選擇本 IRC 帳號最近建立的房間。
- 沒有比賽房間時，即使留有舊開房記錄，也可先連接網站 IRC。新的網站開房指令仍需通過防重送檢查。

下載提供 Windows x64 EXE／ZIP、macOS arm64 DMG／ZIP 與 Linux x64 tar.gz。依既有預覽版流程發布，macOS 安裝檔須通過 Developer ID 簽章與 Apple 公證。
