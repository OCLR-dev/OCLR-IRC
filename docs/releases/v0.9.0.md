# OCLR IRC v0.9.0

OCLR IRC 的首個正式版，提供 Windows x64、macOS Apple Silicon 和 Linux x64 下載。

## 網路代理

- 在「設定 → 網路」選擇直連、SOCKS5 或 HTTP CONNECT。預設為直連，代理須允許免驗證連線。
- 儲存後，新的 IRC 連線、OCLR API 及 osu! 資料請求會採用新設定。目前的 IRC 連線會保留至下次重連。
- HTTP 代理須允許 CONNECT 到 `irc.ppy.sh:6667`。OAuth 授權頁沿用系統瀏覽器的網路設定。

詳見 [網路代理設定](../m1/app-settings.md#網路代理)。安裝包、SHA256 校驗碼及建置資訊見 [v0.9.0 下載](https://github.com/OCLR-dev/OCLR-IRC/releases/tag/v0.9.0)。
