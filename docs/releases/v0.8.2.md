# OCLR IRC v0.8.2

公開預覽版，新增 Windows 與 macOS 原生安裝格式。

## 更新內容

- **Windows x64**：新增 NSIS 安裝精靈 EXE，支援每位使用者安裝、開始功能表與 oclr-irc 協定；重新安裝及卸載保留使用者資料。保留 ZIP 備用版。
- **macOS Apple Silicon arm64**：新增 DMG，開啟後將 OCLR IRC.app 拖到 Applications，再退出映像並從應用程式啟動。正式版本對 App 和 DMG 執行 Developer ID 簽章、Apple 公證與 staple；保留 ZIP 備用版。
- **Linux x64**：維持 tar.gz。
- **發布驗證**：五個成品共用精確版本／完整提交與 SHA-256。Windows CI 實際安裝、啟動、重新安裝及卸載；macOS CI 掛載 DMG、核對內部簽章與離線啟動。缺少或損壞任何必要成品即停止發布。
- 包含 v0.8.1 的自動帳號核對與 refresh 圖示；底線＝空格、忽略大小寫，無需人工配對勾選。

## 使用及驗收範圍

- Pre-release、非 Latest；不代表完整 MVP、真實 Bancho／OAuth 或三平台實機驗收完成。
- Windows 尚未配置發行簽章；macOS 正式簽章／公證狀態以本次 Release CI 與 build-info.json 為準。
- 原生 CI 的重新安裝驗證不替代舊版本／真實使用者環境升級及復原驗收。Linux 憑證保存、IME、休眠、provider、系統匣等限制保持原狀。
