# OCLR IRC v0.8.12

- 與支援新版播報的網站連接後，完局比分會顯示實際隊名，例如 `銀河隊 1 - 0 天藍隊`，並帶上下一手 Ban／Pick 提示。連接舊版網站仍可接收原本的比分格式。
- 房間名單以綠色勾號標示已準備的選手。房間設定按需更新，減少聊天中的 `!mp settings` 回覆。
- 自己送出訊息後，聊天會捲動到最新一則。BanchoBot 回報所有選手已準備或本局結束時，桌面端會通知裁判。

本版為公開預覽版，提供 Windows x64 EXE／ZIP、macOS arm64 DMG／ZIP 與 Linux x64 tar.gz。下載、校驗碼及 macOS 簽章資訊見 [GitHub Release](https://github.com/OCLR-dev/OCLR-IRC/releases/tag/v0.8.12)。
