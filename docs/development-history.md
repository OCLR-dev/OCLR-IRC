### 操作記錄與恢復

現有手動變更、開房與網站轉送共用單步操作追蹤。手動操作送出前保存最小恢復記錄（種類、房間、時間與狀態，不含指令或聊天），保存失敗不送出；同房未核對操作會阻擋下一筆一般變更。中止／取消倒數仍須原本權限與節流檢查，可停止追蹤前筆操作後送出；不能取消已交給伺服器的指令。斷線／重啟後待回覆項目改為結果不明，沒有自動重送。

「操作記錄」提供人工核對：停止等待後仍標記結果不明，不假裝成功。已支援的精確 map／abort／aborttimer 回覆顯示「已觀測到對應回覆」，不代表排除外部裁判操作或 exactly-once 保證。其他語義保持待核對。網站操作記錄僅記憶體，換網站身分／場次清除；完整 OCLR 恢復與多步初始化計畫待契約及後續整合。舊開房 guard 仍保守保留未確定歸屬，不冒充 osu UID。

### 裁判常用工具

房內快捷操作可依中文名稱或英文指令搜尋；Cmd／Ctrl＋K 在非輸入區且未組字時只開啟搜尋，不執行指令。選取結果仍使用相同 typed intent、Main gate 與人工預覽確認。聊天區「常用訊息」提供有限模板，只插入草稿且保留原文，最後由裁判自行傳送；草稿不因模板插入而落盤。真實跨平台 IME／輔助工具仍需實機驗收。

OCLR「帳號配對」分別顯示 IRC 暱稱與網站帳號。暱稱相符仍需勾選人工核對，才可啟用網站 IRC 投影與其衍生指令；這不是 IRC UID 證明。重連、改名、登出或切換網站身分會清除核對，晚到回覆不能沿用舊確認。本人場次唯讀查閱不依賴 IRC 配對。正式網站版本、指派與撤權聯調仍待外部驗收。

CI 內測壓縮包會在上傳前核對 SHA256／build identity 並解壓啟動實際成品（獨立空白 profile）。三平台實際結果見對應 commit 的 workflow；此檢查不取代 IME／休眠／安全 provider／升級實機驗收。

開房恢復資料使用 schema 2，按正規化 IRC 暱稱雜湊隔離。舊版未分帳號資料只保留不含房號的未知結果標記，不推定歸屬；每次登入開房前仍須人工核對，不會自動重送。

房內快捷操作新增「連續換圖與 Mods」：明確手動設定、一次預覽，Main 固定房間與版本後逐步送出、讀回核對。失敗／未知／取消／斷線停止後續步驟，不重送或回滾已完成步驟。Freemod 要求個人規則人工確認，NF 不自動加入；目前保留房間既有 ruleset，正式 OCLR 圖池尚未接入。

### 場次開房候選控制器（2026-10-30，#40）

已用合成 context 與真實 IrcSession 驗證開房預覽、派送前重讀、一次性提交、可信回覆來源追蹤、JOIN 後唯讀查詢、逾時不重送及晚到房間隱私處理。正式 context／授權與日誌 hook 未接入前不註冊產品 IPC／UI，不以既有 panel 直接放行。詳見開房流程文件。

OCLR 場次無法準備指令時，會區分取消、賽果已核准、未開放操作與缺少規則；請依顯示原因回網站核對。完整 context 與場次開房仍是未接入正式 API 的候選核心，不能以唯讀 panel 的可用性視為已授權執行。

房間工作區採精簡頂列：「加入」與「新建」使用 HeroUI 對話框；全高右側工具欄提供操作／玩家分頁、獨立捲動，並以三條線圖示收合／展開。寬視窗可拖曳或用分隔線左右鍵調整欄寬；900×640 自動使用圖示導覽與 280px 工具欄，聊天輸入保持可見。左側五個頁面分別使用插頭、對話框、獎盃、文件及歷史時鐘圖示，滑鼠停留可查看頁面名稱。

「新建」會從目前選取且資料有效的 OCLR 場次帶入已保存房名，並顯示來源場次；可手動修改，但仍需確認既有房間。切換場次、登出或資料失效會清除舊來源並取消確認。此為房名帶入，不代表正式 context 開房／初始化或投影已啟用。

### 網站直接開房修復（2026-10-31）

IRC 登入後，在 OCLR 場次核對帳號並按「連接網站 IRC」，沒有選取房間且沒有既有／未知開房結果時，會建立只接收開房指令的連線。網站的「傳送至本機 IRC」將 `!mp make` 送給 BanchoBot；本機沿用持久化防重送、可信回覆、JOIN 與設定／裁判查詢。驗證完成後自動切換為該房間投影。未知結果不重送，開房結果仍須在本機核對；網站不冒稱 socket 寫入已成功建立。

面板規則已相容網站的可選 `exPlayersPerTeam`，保留 1–16 或 null 的驗證、本人指派、PKCE 與帳號配對。瀏覽器網站登入與桌面授權仍為獨立 session。

設定位於側欄底部齒輪；原本「轉入背景／退出程式」區塊已移除。背景執行預設開啟以延續既有行為，語言預設跟隨系統。設定只保存背景開關與語言，不保存帳號或聊天。詳見 [應用程式設定](m1/app-settings.md)。

網站執裁頁可按「開啟 OCLR IRC」，以 `oclr-irc://connect?fixture=<UUID>` 帶入場次；請使用最新版封裝程式。桌面登入 IRC 並按「繼續連接」後接續原 OCLR 授權／帳號核對流程。Linux 解壓後另執行成品內的 `install-protocol.sh`。連結不攜帶憑證或自動送指令。詳見 [網站 IRC 投影](m1/website-irc-relay.md)。
