# 記錄中心

2026-11-03（#101），將「本機日誌」與「操作記錄」整合為單一導覽入口，使用免費 HeroUI Tabs 切換「聊天日誌」與「操作記錄」。左側保留裁判工作臺、IRC 聊天、記錄中心及獨立設定入口。

## 行為

- 聊天日誌沿用讀取歷史、對話範圍、加密保存開關、匯出及清除。進入記錄中心只查詢保存狀態，不自動讀取歷史內容；由使用者按讀取按鈕取得目前帳號的記錄。
- 同頁切換分頁會保留已載入的聊天內容及範圍選擇；非作用中分頁隱藏且不可操作。離開聊天分頁會取消尚未提交的刪除確認。離開整個記錄中心或切換帳號則卸載舊聊天內容。
- 操作分頁沿用目前帳號的操作結果、未知結果及人工核對；離開分頁即清除尚未提交的核對勾選，返回時必須重新確認。切換分頁不改變 Main 的操作狀態，不送出或重送 IRC 指令。
- 房內工具的「前往操作記錄核對」直接開啟記錄中心的操作分頁。分頁名稱支援繁中、簡中與英文，保留標準鍵盤導覽。

## 隱私與儲存

此項只整合 renderer。聊天日誌與操作恢復仍使用原有 Main API、儲存及清理規則，不合併資料表、保存期限或匯出範圍。OCLR 房間／私人場次排除、加密 provider 不可用時不落明文、7 天清理、未知結果不重送均沿用原限制。

聊天分頁保留掛載時仍訂閱原有 invalidate 事件，登出、帳號變更或房間隱私範圍變更會清理顯示內容、範圍與待確認動作。記錄中心另以 IRC 帳號 key 重建，避免新帳號沿用舊內容。Main 仍在每次讀取、匯出、清除與人工核對時重新驗證來源及範圍。

## 驗證

既有完整 Electron smoke 增加單一導覽／標題、900×640、鍵盤左右切換、日誌範圍及內容保留、非作用中面板隱藏、離頁清除刪除／人工核對確認，以及原本登出取消匯出和清理內容的回歸。核心日誌、provider、命令及操作恢復測試保留。證據使用合成 IRC、帳號及記錄；不代表真實平台 provider 或正式 OCLR 歷史已完成驗收。
