# 裁判工作臺

2026-11-03（#99），依使用者要求將原本「帳號連線」與「OCLR 場次」合併為單一入口。實際聊天工作區改名為「IRC 聊天」，本機日誌、操作記錄與設定保持各自入口。

## 操作與版面

- 上方同頁顯示 osu! IRC 與 OCLR 網站連線。IRC 未登入時提供既有 HeroUI 表單、保存登入及取消；已登入時顯示 48 px 頭像、名稱與「開啟 IRC 聊天」。伺服器／取得專用密碼資訊收在「連線資訊」。OCLR 區提供瀏覽器授權、比對碼、取消，以及已登入帳號的重新整理／登出。
- 已授權後，在連線區下方顯示帳號配對與網站投影，再接本人指派場次和賽前準備／BP 圖池／賽後核對。大視窗使用場次列表，900×640 使用既有場次選單與可捲動內容。
- 單獨完成 IRC 登入仍可進入聊天；已有 OCLR 授權或網站帶入場次時，登入 IRC 後留在工作臺。聊天側欄的場次來源連接與網站深連結均導向同一工作臺。切換到聊天後可隨時返回查看既有場次。
- 導覽使用獨立工作臺、聊天、文件、歷史圖示，窄視窗保留標籤提示。介面名稱提供繁中、簡中與英文，沿用現有紫色主題、Button、TextField、Checkbox、Select、Avatar 與 Tabs。

## 狀態與權限

本項整合 renderer 導覽與版面，IRC 與 OCLR 仍為獨立 Main session。IRC 登出清理密碼、頭像及 IRC 連線；OCLR 授權仍保留。OCLR 登出清理私人場次、配對及投影，IRC 仍可聊天。沒有新的憑證／token 保存、API 或任意指令入口。

OCLR 新鮮度、本人指派、帳號配對、深連結驗證與送前核對沿用原有流程。回到工作臺或聊天不重送已送出的訊息、開房或房內變更；本項不替代完整 context、真實服務與平台實機驗收。
